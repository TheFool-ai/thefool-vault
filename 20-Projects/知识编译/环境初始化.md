## 部署知识编译

1. 打开 [Koala 环境部署流水线](https://koala.web.bytedance.net/#/devops/pipeline?space_id=690f23250ce6fa0018134e1e&cycle_id=6a1405a7a755ac001827a232)。
2. 选择需要部署的版本，例如 **2.6.0**。
3. 将“同时部署知识编译”选项设为 **true**，运行流水线。
4. 等待执行成功，预计耗时约 **2 小时**，再配置功能开关。

## 配置功能开关

进入目标环境的管理后台，在“开关配置”中设置：

```text
https://<目标环境域名>/marketing_agent/42/knowledge-base/admin-console/home
```

[管理后台示例](https://e168-24-109marketingagent.datarangers-onpremise.volces.com/marketing_agent/42/knowledge-base/admin-console/home)，实际使用时替换为目标环境域名。

### 先开总开关

配置项：`switch_knowledge_compile`

```json
{"switch":"open"}
```

### 再按需开启子能力

配置项：`switch_knowledge_compile_qa_scope`

全量开启示例：

```json
{"data":["graph","ontology","semantic","wiki"]}
```

| 枚举值 | 子能力 |
| --- | --- |
| `ontology` | 本体语义 |
| `graph` | 知识图谱 |
| `semantic` | 数据语义 |
| `wiki` | LLM Wiki |

**先开启总开关，再按需开启子能力；总开关开启后，至少开启一个子能力。**

例如只开启本体语义：

```json
{"data":["ontology"]}
```
